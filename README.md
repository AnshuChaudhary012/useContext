# useContext

A React application built with Vite, Tailwind CSS, and React Router.

## Getting started

```sh
npm install
npm run dev
```

## Available routes

- `/` — Home
- `/about` — About
- Any unmatched URL — Not found

## Language switcher

Use the navbar button to switch between English and Hindi. See
[LANGUAGE_CONTEXT.md](./LANGUAGE_CONTEXT.md) for a simple explanation of how
the shared language state works with React Context.

## Scripts

- `npm run dev` — Start the development server
- `npm run build` — Create a production build
- `npm run preview` — Preview the production build
- `npm run lint` — Run Oxlint
